# fortyk-packages

A monorepo containing the **Fortyk** family of reusable NuGet packages and build tooling for .NET projects.

## Packages

| Package | Description |
|---|---|
| [Fortyk.Tooling.Tailwind](src/Fortyk.Tooling.Tailwind/) | MSBuild integration for the [Tailwind CSS](https://tailwindcss.com/) standalone CLI. Automatically downloads and runs the CLI during build — no Node.js or npm required. |

See each package's own README for installation and configuration details.

## Repository Layout

| Path | Description |
|---|---|
| `src/` | Source for the publishable packages |
| `samples/` | Sample applications demonstrating package usage |
